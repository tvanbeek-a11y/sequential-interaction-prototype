# sequential-interaction-prototype
all projects for code tech form and code class

**Live site:** https://tvanbeek-a11y.github.io/sequential-interaction-prototype/

The live site is **Thaw**, the sequence prototype: strike a match, light the torch, throw it onto the wood pile, then push the block of ice into the fire to free the bird frozen inside. Built from the four interaction studies in the ZIP files (strike-a-match, light-the-torch, torch-throw, ice-vs-fire) as one linear sequence; the same match, torch and wood pile carry through. The site lives in `/docs` (plain HTML, CSS and JavaScript, no build step).
